# Gestor de Estoque

## Sistema de almoxarifado

Uma interface de estoque inspirada em sistemas administrativos: painel, catálogo
de produtos, movimentações e lançamento de entrada por nota fiscal.

Instale a dependência e execute, no terminal dentro da pasta `gestor de dados`:

```powershell
py -m pip install -r requirements.txt
py registrador_usuarios.py
```

`gestor_estoque.py` e `registrador_usuarios.py` iniciam a mesma interface.

Se o sistema informar que `customtkinter` está ausente, confirme que a
instalação foi feita com o mesmo comando `py` usado para iniciar o programa.
