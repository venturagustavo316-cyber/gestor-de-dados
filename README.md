# Gestor de dados

## Demonstração de almoxarifado

Uma interface de estoque inspirada em sistemas administrativos: painel, catálogo
de produtos, movimentações e lançamento de entrada por nota fiscal.

Execute, no terminal do projeto:

```powershell
py registrador_usuarios.py
```

`gestor_estoque.py` também permanece disponível como atalho alternativo para a
nova interface.

Dependência da interface: `customtkinter`.
